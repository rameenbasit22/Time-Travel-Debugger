
# Time-Travel Debugger

## Phase 01 - Server Side

The Time-Travel Debugger is a client-server based debugging system.

In Phase 01, the server receives a source program written in the custom C-- language and processes it through the following stages:

1. Receive source.bin
2. Pass 0 - Validation
3. Pass 1 - Resolve
4. Pass 2 - Execution
5. Pass 3 - Serialization

The final output is a `.tdbg` file containing the execution history.

## Environment

- Ubuntu Linux
- C++
- Git/GitHub
